# Online Retail Sales & Customer Analytics

## Project Overview

This is a Data Analytics major project that analyzes online retail transaction data to identify sales trends, country-wise performance, product sales and customer transaction patterns.

## Objectives

- Clean and prepare retail transaction data.
- Analyze sales performance and trends.
- Identify top-performing countries and sales periods.
- Compare registered and guest transaction groups.
- Build an interactive Power BI dashboard.

## Tools & Technologies

- **Python:** Data cleaning and exploratory data analysis
- **Pandas:** Data manipulation and analysis
- **Jupyter Notebook:** Python development environment
- **MySQL:** Database storage and SQL analysis
- **Power BI:** Interactive dashboards and data visualization
- **Microsoft Excel:** Dataset preparation and review

## Dataset

The project uses online retail transaction data with fields such as Invoice Number, Product Code, Description, Quantity, Invoice Date, Unit Price, Customer ID and Country.

Additional analytical columns include Year, Month, Month Name, Day Name, Hour, Quarter, Sales Amount, Revenue Category, Quantity Category and Customer Type.

The final cleaned CSV recorded **524,878 rows and 19 columns**.

## Project Workflow

1. Imported and explored the dataset using Python.
2. Inspected missing values and cleaned selected data-quality issues.
3. Converted transaction dates and created time-based columns.
4. Calculated Sales Amount using Quantity × Unit Price.
5. Performed exploratory data analysis and grouped sales summaries.
6. Imported the cleaned CSV into MySQL.
7. Developed Power BI visuals, KPI cards and slicers.
8. Summarized findings and business recommendations.

## Key Findings

- The United Kingdom had the highest reported country-wise sales amount.
- November had the highest monthly sales among the reported results.
- Registered-customer transactions contributed most of the recorded sales amount.
- Q4 was the highest-performing quarter in the recorded analysis.
- Thursday had the highest reported weekday sales amount.

*Note: Verify all figures against the final cleaned dataset and dashboard before presenting the results.*

## Business Recommendations

- Study the UK market to understand its contribution to sales.
- Plan inventory and promotional activities around stronger sales periods.
- Analyze customer purchasing patterns and repeat transactions.
- Use dashboard filters to investigate country and product performance.
- Improve data quality and monitor missing customer identifiers.

## Conclusion

This project demonstrates an end-to-end data analytics workflow using Python, MySQL and Power BI. It converts retail transaction data into summaries and visual insights that can support business decisions.
